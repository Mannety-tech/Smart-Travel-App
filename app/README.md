## 3. Running the App
1. Connect an Android device or start an emulator
2. Select the 'app' configuration
3. Click Run in Android Studio.
4. The app will launch on your devices.

## 4. Troubleshooting 
If gradle fails,clicks **file -> Sync project with gradle files**
If maps doesn't load, check the API key.
If weather or flight data fails,verify your API limits.
